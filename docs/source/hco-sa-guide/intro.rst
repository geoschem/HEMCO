.. _hco-sa-guide:

####################################
Introduction to the HEMCO Standalone
####################################

In this **HEMCO Standalone User Guide**, you will learn how to run
HEMCO in **standalone mode** (i.e. not connected to an external model).

For more information about how to configure HEMCO simulations and how
to interface HEMCO to external models, please see the :ref:`HEMCO
Reference Guide <hco-ref-guide>`.
